Private parking map: Melbourne CBD

Friday 11 October 2019 · on-street parking sensors · Mastic private heavy hitters

Each parked car's phone reports, for every hour, whether it is parked at h:30 and in which area, as secret shares to two servers running Mastic. The servers learn only the busy areas (at least τ = 1 % of all reports) and how many cars stood there each hour, never an individual parking event. Combined with the public number of bays, the map shows how full each area is and where spaces are likely free. This page only reads the saved results of that run.
